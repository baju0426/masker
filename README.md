# masker — 문서 개인정보 자동 가명처리 도구

한글(HWP)·PDF·워드 문서를 Markdown으로 바꾸면서, 문서 속 **이름·소속·연락처·주소·주민등록번호** 같은 개인정보를 자동으로 가려 주는 Windows용 도구입니다.

- 파일을 `mask_drop.bat` 위에 **끌어다 놓기만 하면** 끝
- **내 컴퓨터 안에서만** 처리합니다. 문서 내용을 인터넷으로 보내지 않습니다.
- 같은 사람은 문서 전체에서 **같은 가명**으로 바꾸고, 뒤에 붙는 조사(은/는, 이/가)도 맞춥니다.

## 바뀌기 전과 후

```text
[원본]
신고인: 김영희 (연락처 010-1234-5678)
대상자: 동부구청 민원과 주무관 홍길동(52세)
홍길동은 3월 5일 민원 전화를 받고 김영희 씨에게 회신하지 않았다.
주소: 서울특별시 중구 세종대로 110, 101동 1203호

[결과]
신고인: 갑 (연락처 010-****-****)
대상자: A구청 민원과 주무관 을(○○세)
을은 3월 5일 민원 전화를 받고 갑 씨에게 회신하지 않았다.
주소: [주소]
```

## 가리는 항목

| 항목 | 예시 결과 |
| --- | --- |
| 이름 (직급·역할 옆, "성명:" 뒤, 표의 성명 칸, "씨/님" 앞) | 갑, 을, 병 … |
| 소속 기관 (소방서·안전센터·경찰서·구청·주민센터·학교 등) | A소방서, A구청 … |
| 주민등록번호 / 생년월일 / 나이 | `******-*******` / `****. *. *.` / `○○세` |
| 전화번호 | `010-****-****` |
| 주소 / 아파트 동·호수 | `[주소]` / `○○동 ○○호` |
| 차량번호 / 계좌번호 / 이메일 | `**○ ****` / `***-**-***` / `[이메일]` |
| 업체명 (표의 상호·대상물명 칸) | `[업체A]` |

| 프로그램 | 필요한 경우 | 설치 |
| --- | --- | --- |
| [Node.js](https://nodejs.org) 18 이상 | 항상 | LTS 버전 설치 |
| [kordoc](https://github.com/chrisryugj/kordoc) | HWP·HWPX·PDF·DOCX·XLSX를 넣을 때 | 명령 프롬프트에서 `npm install -g kordoc` |

## 설치

1. 이 페이지의 **Code → Download ZIP** 으로 내려받습니다.
2. OneDrive가 **아닌** 폴더에 압축을 풉니다. (예: `C:\가명처리`)
3. 명령 프롬프트(cmd)에서 그 폴더로 이동해 점검합니다.

```bat
cd C:\가명처리
node masker.js --test
```

`[정상] 프로그램이 올바르게 작동합니다.` 가 나오면 준비 끝입니다.

## 사용법

| 이럴 때 | 끌어다 놓을 곳 |
| --- | --- |
| 문서 1개, 또는 서로 관계없는 문서들 | `mask_drop.bat` |
| 한 사건의 문서 여러 개 (같은 사람 = 같은 가명) | `mask_drop_shared.bat` |

원래 파일 옆에 `masked` 폴더가 생기고, 그 안에 결과가 만들어집니다.

- `원래이름_masked.md` — 가려진 문서 (다른 사람·AI에게는 이것만 넘기세요)
- `원래이름_masked.pdf` — 같은 내용을 읽기 좋게 만든 PDF. **가려진 부분이 노란색**으로 칠해져 있어 확인하기 쉽습니다
- `원래이름_mapping.csv` — 원문↔가명 대조표 (**실명 포함, 따로 보관**)
- `case_mapping.csv` — `mask_drop_shared.bat` 를 쓸 때 생기는 **사건 대조표** (실명 포함, 따로 보관)

PDF는 Windows에 기본으로 깔린 **Edge**(없으면 Chrome)를 화면 없이 잠깐 띄워 인쇄하는 방식으로 만듭니다. 문서 내용은 밖으로 나가지 않습니다. 브라우저를 찾지 못하면 대신 `_masked.html` 을 만들어 두니, 열어서 `Ctrl+P` → PDF로 저장하세요.

### 참고인·진술인이 계속 늘어날 때 (사건 대조표)

한 사건의 문서는 **같은 폴더**에 모으고 `mask_drop_shared.bat` 로 처리하세요. `masked\case_mapping.csv` 에 지금까지 나온 사람과 가명이 쌓이고, 다음 문서를 처리할 때 이어서 씁니다.

| 날짜 | 문서에 나온 사람 | 결과 |
| --- | --- | --- |
| 25일 | 홍길동, 이민수, 최지은 | 갑, 을, 병 |
| 26일 | 이민수, 홍길동, 박철수, 정은비 | 을, 갑, **정, 무** (새 사람만 다음 가명) |

이미 변환한 25일 파일은 **다시 변환할 필요가 없습니다.**

- 이미 진행 중인 사건이라면, 지금까지의 문서를 한꺼번에 한 번 `mask_drop_shared.bat` 에 끌어다 놓아 대조표를 만든 뒤부터 이어 쓰세요.
- 새 사건은 새 폴더에서 시작하세요. 다른 사건과 가명이 섞이지 않습니다.
- `case_mapping.csv` 를 엑셀로 열어 고쳤다면 반드시 **CSV UTF-8** 형식으로 저장하세요. 처리 중에는 엑셀을 닫아 두세요.

연습용 문서는 [`examples/sample.md`](examples/sample.md) 에 있습니다.

### 놓치거나 잘못 가렸을 때

- 놓친 이름 → `names.example.txt` 를 `names.txt` 로 복사해 이름을 한 줄에 하나씩 적기
- 잘못 가린 낱말 → `exclude.example.txt` 를 `exclude.txt` 로 복사해 낱말을 적기

두 파일 모두 UTF-8로 저장하세요. `names.txt`, `exclude.txt` 는 실명이 들어갈 수 있어 `.gitignore` 로 저장소에 올라가지 않게 해 두었습니다.

### 옵션 (명령 프롬프트에서 직접 실행할 때)

```bat
node masker.js <파일 또는 폴더> [옵션]
```

| 옵션 | 기능 |
| --- | --- |
| `--style gap` | 이름을 갑·을·병으로 (기본) |
| `--style abc` | 이름을 A·B·C로 |
| `--style partial` | 성만 남기고 홍○○로 |
| `--shared` | 여러 문서에 같은 가명 (사건 대조표 이어쓰기) |
| `--out <폴더>` | 결과 저장 폴더 |
| `--no-map` | 대조표 만들지 않음 |
| `--keep-age` | 나이는 그대로 둠 |
| `--keep-biz` | 업체명은 그대로 둠 |
| `--no-pdf` | PDF 만들지 않음 |
| `--no-ai` | AI 이름 찾기 쓰지 않음 |
| `--browser "<경로>"` | PDF 만들 브라우저 직접 지정 |
| `--kordoc "<명령>"` | kordoc 실행 명령 지정 |
| `--test` | 프로그램 자체 점검 |

## AI로 이름 더 찾기 (선택, 시험 기능)

규칙만으로는 "같은 조에 최도시가 있었고"처럼 계급·호칭 없이 나온 이름을 놓칠 수 있습니다. 문장의 앞뒤 흐름을 보고 사람 이름을 찾는 작은 AI 모델([koelectra-ko-pii-ner](https://huggingface.co/atonlee/koelectra-ko-pii-ner), Apache-2.0, 약 15MB)을 **내 PC 안에서만** 함께 돌릴 수 있습니다.

1. `setup_ai.bat` 를 한 번 실행합니다.
   - AI 부품 설치(`npm install @huggingface/transformers`, 약 500MB)
   - AI 모델 내려받기(`get_model.js` → `models\koelectra-ko-pii-ner`)
2. 이후에는 평소처럼 끌어다 놓으면 `[AI] 문맥으로 이름 찾기를 함께 씁니다.` 가 나오며 자동으로 함께 씁니다. 끄려면 `--no-ai`.

- 설치·내려받기 때만 인터넷을 쓰고, 문서를 처리할 때는 인터넷을 쓰지 않습니다(외부 모델 받기 차단 설정).
- 회사망에서 Hugging Face가 막혀 있으면 집 PC에서 `get_model.js` 로 받은 `models` 폴더를 통째로 옮기면 됩니다.
- AI가 고른 이름도 프로그램이 한 번 더 확인합니다(성으로 시작하는 3~4글자, "이동시"·"지시한" 같은 말 제외). 두 글자 이름은 AI만 믿고 가리지 않습니다.
- AI도 틀릴 수 있습니다. 결과 PDF의 노란색 부분을 꼭 확인하세요.

## 꼭 알아 두세요

- 자동 처리는 **1차 작업**입니다. 직급·호칭 없이 문장 속에 이름만 나오는 경우, 두 글자 이름, 별명은 놓칠 수 있으니 결과를 반드시 직접 확인하세요.
- 이름을 지워도 직급·근무지·날짜를 조합하면 누군지 알 수 있습니다(재식별). 외부로 내는 문서는 이런 정보도 필요한 만큼 일반화하세요.
- 스캔(이미지) PDF는 글자를 읽지 못해 가려지지 않습니다.
- 결과 파일 이름에는 원래 파일 이름이 그대로 들어갑니다. 파일 이름에 실명이 있다면 넘기기 전에 이름을 바꾸세요.
- 대조표(`_mapping.csv`, `case_mapping.csv`)는 가명처리의 "추가 정보"에 해당하므로 결과 문서와 분리해 보관하세요.
- **실제 문서나 결과물을 이 저장소에 올리지 마세요.** 이슈나 질문에도 실제 개인정보를 붙이지 마세요.
